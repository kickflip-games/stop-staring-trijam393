Eight cream dust variants from the supplied spritesheets, copied unchanged.
Each sheet contains six 64 x 64 frames with transparency.

Wall impacts choose a random variant without immediate repeats, with varied
size, playback speed, flip, and angle. Bursts face into the arena and clean
themselves up when their non-looping animation finishes. Tune `WallDust` in
the main scene for pixel size, frame rate, and the active-burst limit.
